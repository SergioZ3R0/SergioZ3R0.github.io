About

Systems engineer focused on High Performance Computing. I build CLI tools and TUIs that simplify GPU benchmarking and Slurm cluster management for HPC environments.

My tools are used to baseline GPU hardware at delivery, run HPL & HPCG benchmarks, monitor Slurm jobs, and automate infrastructure audits — all from the terminal.

Everything is open source under Apache 2.0. Contributions, issues, and feature requests are welcome on GitHub.
